# 🐍 Snake Game

لعبة Snake بسيطة للأندرويد، مبنية بـ Kivy.

## 🎮 اللعب
- اسحب بإصبعك على الشاشة عشان تتحكم بالثعبان
- كل تفاحة = 10 نقاط
- لما تصطدم بالحواف أو بنفسك = نهاية اللعبة

## 📥 التحميل
روح على [Actions](https://github.com/ayman7990-tech/snake-game/actions)
وحمل أحدث APK.

## 🛠️ التقنيات
- Python 3.10
- Kivy
- Buildozer
